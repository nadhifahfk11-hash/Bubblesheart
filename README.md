## ✨ Fitur-Fitur Website
- 🎀 **Estetika Glassmorphism Modern**: Panel kartu transparan bergaya kaca lembut berpadu dengan aksen warna pink & biru.
- 🫧 **Animasi Gelembung Melayang (Floating Bubbles)**: Gelembung interaktif yang mengapung di layar dan dapat diletuskan saat diklik!
- 🔊 **Efek Suara "Pop" Interaktif**: Dihasilkan secara langsung menggunakan *HTML5 Web Audio API* (tanpa perlu unduh file audio tambahan).
- 🦋 **Animasi Kupu-Kupu & Bintang**: Ornamen kupu-kupu yang mengepakkan sayapnya secara dinamis di sisi layar.
- 📱 **Desain Responsif**: Tampilan tetap rapi dan nyaman dilihat di layar Laptop, Tablet, maupun HP.

---

## 🚀 Cara Menjalankan Proyek
1. Buka file `index.html` langsung di browser Anda (Google Chrome, Edge, Firefox).
2. Untuk mengaktifkan website ini agar bisa diakses online oleh siapa saja:
   - Masuk ke tab **Settings** di repositori GitHub ini.
   - Buka menu **Pages** di sebelah kiri.
   - Pada bagian **Build and deployment**, pilih branch `main` (atau `master`) dan folder `/ (root)`.
   - Klik **Save**, dan website Anda akan aktif online melalui **GitHub Pages**! 🎉
